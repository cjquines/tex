\subsubsection*{Valuation}

Let $p$ be a prime. The \textbf{$\boldsymbol{p}$-adic valuation} of a positive integer $n$, written $\nu_p(n)$,\footnote{
  The $\nu$ here is the Greek letter $\nu$ (spelled \textit{nu}, pronounced ``new''), presumably chosen for visual similarity to $v$, for \textit{valuation}. When reading aloud, I pronounce $\nu_p$ as ``vee pee''.
} is the largest integer $e$ such that $p^e \mid n$.
In particular, \[
  \nu_p(n) = e \iff p^e \mid n,\,p^{e+1}\nmid n.
\]

\subsubsection*{Warmup}

\begin{enumerate}

\item (Product rule) Prove that $\nu_p(ab) = \nu_p(a) + \nu_p(b)$. Use this to extend the definition of $\nu_p$ to $\QQ_{\ne 0} \to \ZZ$. By convention, we set $\nu_p(0) = \infty$.

\item (Sum rule) Prove that $\nu_p(a + b) \ge \min\cbr{\nu_p(a), \nu_p(b)}$. Prove that if $\nu_p(a) \ne \nu_p(b)$, then equality holds. Find an example where $\nu_p(a) = \nu_p(b)$, yet equality holds.

\item (\href{https://en.wikipedia.org/wiki/Hasse_principle}{Local--global principle}) Prove that $\nu_p(a) \le \nu_p(b)$ for all primes $p$ if and only if $a \mid b$. What does this tell you about $\nu_p(\gcd(a, b))$ and $\nu_p(\lcm(a, b))$?

\item (\href{https://en.wikipedia.org/wiki/Ostrowski's_theorem}{Ostrowski's theorem}) Let $\nu \from \ZZ_{\ne 0} \to \NN \cup \{0\}$ be a non-constant function satisfying $\nu(ab) = \nu(a) + \nu(b)$ and $\nu(a + b) \ge \min\cbr{\nu(a), \nu(b)}$. Prove there's some prime $p$ such that $\nu = \nu_p$.

\end{enumerate}

\noindent
These are all the $\nu_p$ properties we need. Some important results I won't discuss, but you should learn later: \href{https://en.wikipedia.org/wiki/Legendre's_formula}{Legendre's formula}, \href{https://en.wikipedia.org/wiki/Kummer's_theorem}{Kummer's theorem}, \href{https://cjquines.com/files/liftingtheexponent.pdf}{Lifting the exponent}.

\subsubsection*{Examples}

\begin{enumerate}

\item Positive integers $a$, $b$, and $c$ satisfy $a \mid b^3$, $b \mid c^3$, and $c \mid a^3$. Prove that $abc \mid (a + b + c)^{13}$.

\textbf{Sketch:} It's enough to show for all primes $p$ that $\nu_p(abc) \le \nu_p\del{(a + b + c)^{13}}$, or that $\nu_p(abc) \le 13 \min\cbr{\nu_p(a), \nu_p(b), \nu_p(c)}$. The given conditions translate to \[
  a \mid b^3,\;b \mid c^3,\;c \mid a^3 \iff \nu_p(a) \le 3 \nu_p(b),\;\nu_p(b) \le 3\nu_p(c),\;\nu_p(c) \le 3\nu_p(a).
\]
This means that \[
  \nu_p(abc) = \nu_p(a) + \nu_p(b) + \nu_p(c) \le \nu_p(a) + 3\nu_p(c) + 3\nu_p(a) \le \nu_p(a) + 9\nu_p(a) + 3\nu_p(a),
\]
which is $13\nu_p(a)$. Similarly, $\nu_p(abc) \le 13\nu_p(b)$ and $\le 13\nu_p(c)$, so it's less than their minimum.

\textbf{Remark 1:} Problems with divisibility, multiplication, exponentiation, or GCDs and LCMs, are good candidates for using $\nu_p$ on. It works less well with addition, but it can happen.

\textbf{Remark 2:} I'm going to start omitting the \textit{it's enough to show that, for all primes $p$} part in the sketches, but you should definitely say it in full solutions.

\item (\href{https://artofproblemsolving.com/community/c291h1904123p13026024}{BAMO 2018/4}) Show that if $a, b, c$ are nonzero integers such that $a/b + b/c + c/a$ is an integer, then $abc$ is a perfect cube.

\textbf{Sketch:} Note that $abc$ is a perfect cube if and only if $3 \mid \nu_p(abc)$ for all primes $p$. Let $x, y, z := \nu_p(a), \nu_p(b), \nu_p(c)$ respectively; we want to show $3 \mid x + y + z$. Because it's an integer, we have $\nu_p(a/b + b/c + c/a) \ge 0$. By the sum rule, we also have \[
  \nu_p(a/b + b/c + c/a) \ge \min\cbr{ \nu_p(a/b), \nu_p(b/c), \nu_p(c/a) } = \min\cbr{x-y, y-z, z-x},
\]
an inequality we can't use yet. We can make it an equality if we think about distinctness. Doing casework on the number of distinct integers in $\cbr{x-y, y-z, z-x}$:

\begin{itemize}
\item Suppose all were distinct. This gives the equality case: $0 \le \nu_p(a/b + b/c + c/a) = \min\cbr{x-y, y-z, z-x}$. As the three integers sum to $0$, if they're all distinct, one of them must be negative. Then their minimum would be negative, contradicting the fact that $\nu_p(a/b + b/c + c/a) \ge 0$.

\item Otherwise, two of them are equal. WLOG $x-y = y-z$. Then $x + y + z = 3y$, which is divisible by $3$, as desired.

\end{itemize}

\textbf{Remark:} In general, an equality case of the sum rule is much more useful, and it's usually worth doing casework to make it happen.

\item (\href{https://artofproblemsolving.com/community/c6h1871281p12694557}{Poland 2nd 2019/3--}) Two sequences of rational numbers $q_1, q_2, \ldots$, and $r_1, r_2, \ldots$ satisfy \[
  q_1r_1 = 3, \quad
  q_{n+1} = q_n^5 + q_n, \quad \text{and} \quad
  r_{n+1} = r_n^7 + r_n.
\]
Can there exist positive integers $m$ and $n$ such that $q_m = r_n$?

\textbf{Sketch:} No. We work entirely in $\nu_3$, and think about the sizes of terms in $\cbr{\nu_3(q_n)}$. We have \[
  \nu_3(q_2) = \nu_3(q_1) + \nu_3(q_1^4 + 1) \ge \nu_3(q_1) + \min\cbr{4\nu_3(q_1), 0}.
\]
We do casework on the sign of $\nu_3(q_1)$, so we can get an equality case.

\begin{itemize}

\item Suppose $\nu_3(q_1) = 0$. Then $q_1 \perp 3$,\footnote{Here, $a \perp b$ means $a$ and $b$ are relatively prime.} so by Fermat's little, $q_1^4 + 1 \equiv (q_1^2)^2 + 1 \equiv 2 \pmod 3$, so $\nu_3(q_1^4 + 1) = 0$ as well. By the first equality above, we get $\nu_3(q_2) = \nu_3(q_1)$. We can then induct to get that $\cbr{\nu_3(q_n)}$ is constant.

\item If $\nu_3(q_1) > 0$, we have $4\nu_3(q_1) \ne 0$, so we have the equality case. Then $\nu_3(q_2) = \nu_3(q_1) + \min\cbr{4\nu_3(q_1), 0} = \nu_3(q_1)$. Induction again shows $\cbr{\nu_3(q_n)}$ is constant.

\item If $\nu_3(q_1) < 0$, we similarly get $\nu_3(q_2) = 5\nu_3(q_1) < \nu_3(q_1)$. In this case, induction shows $\cbr{\nu_3(q_n)}$ is decreasing.

\end{itemize}

Similar statements hold for $\cbr{\nu_3(r_n)}$.

In $\nu_3(q_1) + \nu_3(r_1) = 1$, the two addends are integers, so WLOG $\nu_3(q_1) > 0 \ge \nu_3(r_1)$. Then $\nu_3(q_m) = \nu_3(q_1) > \nu_3(r_1) \ge \nu_3(r_n)$, so no two terms can be equal.

\textbf{Remark:} This is a kinda contrived example, but the theme of ``$p$-adic valuation of sequence is monotonic'' appears often enough that I've made a separate section of problems for it. For a decreasing sequence of \textit{integers}, if there's a lower bound, it's eventually constant. This is helpful for $\nu_p$, because it's always an integer, and the $\nu_p$ of an integer is always $\ge 0$.

\end{enumerate}

\subsubsection*{Hints}

\begin{enumerate}

\item \label{h:4-1} \label{h:9-1} \label{h:11-1} Telescope the conditions.

\item \label{h:5-1} To prove odd impossible, take $\nu_2$.

\item \label{h:6-1} Do casework on number of $x_i$ such that $\nu_p(x_i) = \nu_p(k)$.

\item \label{h:7-1} Show $\nu_2$ of something is strictly decreasing.

\item \label{h:7-2} Look at $\nu_2(a_i - 3/2)$.

\item \label{h:8-1} Show $a_n \mid C$.

\item \label{h:8-2} If $a_n > \nu_p(C)$, show $\cbr{\nu_p(a_i)}_{i \ge n}$ is decreasing.

\item \label{h:9-2} Divide geometric mean conditions for $(1, d+1)$ and $(2, d+2)$, and note $d$ is arbitrary.

\item \label{h:10-1} Show $\nu_p(c) > 1$ is impossible due to eventual periodicity.

\item \label{h:10-2} Show that $c$ having two distinct prime divisors is impossible when $a_1 = c$.

\item \label{h:10-3} Show $c$ divisible by an odd prime $> 3$ is impossible.

\item \label{h:11-2} Simplify the difference of terms. If you subtract $1$, the numerator factors.

\item \label{h:11-3} Consider the sequences $\cbr{\gcd(a_1, a_n)}$ and $\cbr{\lcm(a_1, a_n)}$.

\item \label{h:12-1} Let $e := \nu_p(b)$, and take $k = p^{e+1}$.

\item \label{h:13-1} This is similar to BAMO 2018/4.

\item \label{h:13-2} If $\nu_p(a) > 0$, WLOG $\nu_p(b) < 0$. Show $\nu_p(c) < 0$.

\item \label{h:13-3} If $\nu_p(a) > 0$, show $y\nu_p(b) = z\nu_p(c)$.

\item \label{h:14-1} What are the invariants?

\item \label{h:14-2} The sum is invariant, and all numbers are non-negative.

\item \label{h:14-3} At the start, all $\nu_p \le 0$; at the end, all $\nu_p > 0$.

\item \label{h:15-1} Prove a sequence is good iff $n \mid a_n^2$ and $a_n \mid n^2$.

\item \label{h:15-2} Combine $(n, 2n)$, $(2n, 3n)$, $(n, 3n)$ to get $n \mid 2a_n^2$.

\item \label{h:15-3} Choose $(m, n)$ to try getting an equality case for the sum rule.

\item \label{h:16-1} Take $x_p$ such that $e_p := \nu_p(f(x_p))$ is maximal.

\item \label{h:16-2} Choose $n$ such that $\nu_p(n) = e_p$.

\item \label{h:16-3} Use CRT to choose $m$ such that $\nu_p(x - x_p) = \nu_p(x + m)$.

\item \label{h:17-1} Show $g$ is injective mod $p$.

\item \label{h:17-2} Equivalently, show $p \mid g(b) - g(a)$ implies $p \mid a - b$.

\item \label{h:17-3} Choose $m$ to force $\nu_p(g(a) + m)$ and $\nu_p(g(b) + m)$ to both be odd.

\item \label{h:17-4} By injectivity, $p \nmid g(n+1) - g(n)$.

\end{enumerate}

\subsubsection*{Sketches}

\begin{enumerate}

% India Regional 2013
\item Let $a, b, c := \nu_p(a_1), \nu_p(b_1), \nu_p(c_1)$ respectively. WLOG $a \le b \le c$. Then $\nu_p(a_2) = b$ and $\nu_p(b_2) = \nu_p(c_2) = a$. Similarly, $\nu_p(a_3) = a$ and $\nu_p(b_3) = \nu_p(c_3) = b$. So $\nu_p(a_2 \gcd(b_2, c_2)) = a + b = \nu_p(a_3 \lcm(b_3, c_3))$.

% Poland 1983
\item Let $w, x, y, z := \nu_p(a), \nu_p(b), \nu_p(c), \nu_p(d)$ respectively. Want to show $\min\cbr{w, y} + \min\cbr{w, z} = w + \min\cbr{w, x, y, z}$. Per $ab = cd$, RHS here is $w + \min\cbr{w, y + z - w, y, z}$. Casework on relative sizes of $\cbr{w, y, z}$ finishes: symmetry of $y$ and $z$ rule out half the cases.

  % (a1 ... an)[a1 ... an] = a1 ... an
\item Condition is $\min_i\cbr{\nu_p(a_i)} + \max_i\cbr{\nu_p(a_i)} = \sum_i \nu_p(a_i)$. WLOG, suppose $\nu_p(a_1)$ is the minimum and $\nu_p(a_n)$ is the maximum. Then this is $\sum_{1 < i < n} \nu_p(a_i) = 0$, so all the middle $a_i$ (of which there are $\ge 1$, because $n \ge 3$) must all be $0$. So the minimum must also be $0$. This means, for each $p$, there's only one $a_i$ such that $p \mid a_i$; this proves the result.

% Sozopol 2015
\item Take $p \mid a_1$ and add the inequalities $2 \nu_p(a_n) \le \nu_p(a_{n+1}) + \nu_p(a_{n-1})$ for $n = 1, 2, \ldots, k-1$ to get $\nu_p(a_1) + \nu_p(a_{k - 1}) \le \nu_p(a_0) + \nu_p(a_k)$. But $a_1 \perp a_k$ so $p \nmid a_k$, so $\nu_p(a_1) \le \nu_p(a_0)$.

% USEMO 2020
\item Evens: $(1, \frac{n}{2}, 1)$. We show odd is impossible. Let $a, b, c := \nu_2(x), \nu_2(y), \nu_2(z)$, respectively. If expression was odd, we have $\min\cbr{ \max\cbr{a, b} + \max\cbr{b, c} } = \max\cbr{a, c}$. By symmetry, WLOG $a \le c$. Do casework on relative sizes of $\cbr{a, b, c}$. For the case where $b$ isn't between $a$ and $c$, we have to go back to the original expression to handle the cancellation properly.

% USEMO 2024
\item From parallelogram, $ x_1 + x_3 = x_2 + x_4 $ and $ y_1 + y_3 = y_2 + y_4 $.
